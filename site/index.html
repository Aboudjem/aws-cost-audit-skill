AWS Cost Audit Skill

Ask Claude to audit your AWS bill. Get a clear savings plan where every number is checked against live AWS pricing, and nothing gets deleted without your say-so.

View on GitHub See a sample dashboard 10x marketplace

All figures shown are illustrative (synthetic data, no real account). In a real run every dollar is re-derived live from the AWS Price List Query API for your exact Region.

What it is

A Claude Code skill that audits a live AWS account the way a careful FinOps engineer would: it attributes every dollar, finds the waste, and hands you a plain-language report split into "save now safely" and "maximum theoretical save". It reads only by default, it never guesses a price, and it never deletes anything on its own.

Install it

From the 10x marketplace (recommended), inside Claude Code:

/plugin marketplace add Aboudjem/10x
/plugin install aws-cost-audit@10x

Into another AI CLI (Codex, Gemini, Copilot, and more), one line links the skill into that CLI's skills directory:

curl -fsSL https://raw.githubusercontent.com/Aboudjem/aws-cost-audit-skill/main/install.sh | bash -s codex

You need the AWS CLI configured with read access to the account you want to audit. ReadOnlyAccess is enough.

Why you can trust the numbers

No made-up prices

Every dollar comes from the live AWS price for your Region plus your actual usage, shown as unit price, math, source.

Attribute every dollar

Cost, purpose, owner, created-when, last-used per resource. If a fact cannot be verified, it says "unknown".

Nothing destructive without proof

A change runs only if proven unused, reversible, dry-run-tested, and certain. Otherwise it stays a recommendation.

One sample is never the fleet

A separate skeptic pass re-derives the headline numbers from the source before they ship.

Every finding shows its evidence

Current cost, cost after, dollars saved, a confidence level, the proof, and how to undo it.

No data leaves your machine

It uses your existing AWS CLI credentials locally. Nothing is uploaded to a third party.

See it for yourself

Open the sample dashboard (synthetic data, clearly labelled) to see the report shape: monthly run-rate, "save now safely" vs "maximum theoretical save", and a per-resource view. The sample report shows the per-finding contract in full.
